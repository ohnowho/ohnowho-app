# 设计规范 — OhNoWho

## 整体风格
- 简洁冷淡风，符合 Apple HIG
- 大量留白，文字为主
- 支持浅色 / 深色模式（跟随系统）
- SF Symbols 图标集

## 色彩
| 用途 | 色值（待定） |
|------|-------------|
| 主题色（Accent） | 高级砖红 🧱 |
| 背景 | System Background |
| 文字 | Label Color |
| 地图 Pin | 系统默认红色大头针 |

## 字体
- SF Pro（系统默认字体）

## App 图标
- 符号风格图标（如 ❓ ❗ 📍 等方向待定）

## 地图
- MapKit 标准地图样式
- 笔记 Pin：系统默认红色大头针

## 交互细节
- 删除笔记：不弹确认，直接删除，加 Toast 撤销
- 搜索：输入即搜索，地图实时过滤
